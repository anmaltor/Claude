## Project Overview

A Python project currently containing a simple Hello World script. The repository is in its early stages.

## Repository Structure

```
.
└── hello_world.py    # Entry point — prints "Hello, World!"
```

## Development Environment

- **Language**: Python 3
- **Runtime**: Python 3.11+
- **No external dependencies** — standard library only

## Running the Project

```sh
python3 hello_world.py
```

## Code Conventions

- Use `#!/usr/bin/env python3` shebang for executable scripts
- Include module-level docstrings
- Use a `main()` function with an `if __name__ == "__main__"` guard
- Follow PEP 8 style guidelines

## Git Workflow

- **Default branch**: `master`
- Write clear, imperative commit messages (e.g., "Add feature X", not "Added feature X")
